# hstack telemetry UI

Local dashboard for hstack observability across every consuming repo. Built
with Next.js and `@gomoso-ai/design-system` primitives only — no other UI
library.

Two views:

- **Consolidated (default)** — latest report of each repo side by side, merged
  Skill/subagent/halt tables, the cross-repo watch list, and the **Brain** tab
  showing the workflow recommendations from `../brain/recommendations/`.
- **Per-repo** — the full six-bucket dashboard for one dated report, via the
  picker (grouped by repo; every `report.py` run adds a snapshot).

Dev-tooling for the engineer running hstack; not shipped to consuming repos
(`package.json#files` excludes `ui/`) and strictly read-only.

## One-time setup

```bash
cd ui
cp .env.example .env.local     # set HSTACK_REPOS to your consuming repos
NODE_AUTH_TOKEN=$(gh auth token) npm install   # DS is on GitHub Packages
```

## Run

```bash
npm run dev
```

That's it — Next.js loads `.env.local` automatically. Open
http://localhost:3000.

## Data

Reports are generated by the telemetry script (JSON twin consumed here):

```bash
python3 template/scripts/telemetry/report.py --repo /path/to/consuming-repo --window 30
```

or weekly by `scripts/brain-weekly.sh` (launchd agent
`ai.gomoso.hstack-brain-weekly`), which also runs the brain analysis that
feeds the recommendations tab.
